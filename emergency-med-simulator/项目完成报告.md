## 功能实现对照表

### ✅ 核心约束系统
- [x] **10分钟/32张卡硬约束**: 严格实现双重时间限制
- [x] **资源归零立即结局**: 任意资源=0或=100立即触发结局
- [x] **卡面文字限制**: 正文≤60字，选项≤12字
- [x] **方向性提示**: 只显示↑↓≈符号，无精确数值
- [x] **右上角状态显示**: 剩余卡数/时间实时更新

### ✅ 五阶段有限状态机
- [x] **完整阶段序列**: 医学生 → 研究生/规培 → 博士 → 主任医师 → 院士
- [x] **阶段配额系统**: 每阶段6张卡+1张关卡卡（院士阶段4+1）
- [x] **关卡卡机制**: 阶段末必经关卡，决定是否晋升
- [x] **阶段权重系统**: 不同阶段对各资源有不同权重评分
- [x] **进度可视化**: 五个圆点显示阶段进度，动态更新

### ✅ 隐形StageScore评分系统
- [x] **评分范围**: -100到+100，对用户不可见
- [x] **失败阈值**: StageScore < -10强制失败
- [x] **优秀阈值**: StageScore > 20优秀通过，有额外奖励
- [x] **权重计算**: 基于阶段特定的资源权重实时计算
- [x] **阶段重置**: 每次晋升后StageScore归零

### ✅ 分阶段卡池系统
- [x] **总卡片数量**: 140+张卡片（120常规+20稀有）
- [x] **阶段特色卡片**: 每阶段独特主题和关键词
  - 医学生: 解剖作弊、病例保密、急救优先级
  - 研究生/规培: 值班上报、家属沟通、红线触碰
  - 博士: 署名伦理、数据完整性、照片打码
  - 主任医师: 手术适应证、带教分配、舆情风险
  - 院士: 学术争议、公卫决策、利益冲突
- [x] **稀有事件**: 10%概率触发，跨阶段影响
- [x] **喘息卡机制**: 连续3张负面卡后自动插入

### ✅ 14+种结局系统
- [x] **阶段性结局**: 每阶段2种结局（成功/失败）
- [x] **资源失败结局**: 4种立即结局（安全/知识/道德/精力归零）
- [x] **特殊结局**: 完美平衡、英雄传奇、创新先锋、全球影响力
- [x] **职业画像标签**: 基于最终资源状态生成个性化标签

### ✅ 战报PNG生成系统
- [x] **完整战报内容**: 
  - 成就描述和结局信息
  - 关键决策记录（最多3个）
  - 统计数据（时间、卡数、稀有事件）
  - 资源变化火花线图
  - 职业画像标签
  - 种子复盘信息
- [x] **PNG导出功能**: 使用html2canvas生成高清图片
- [x] **分享文案**: 格式化的社交媒体分享文案
- [x] **种子复盘**: 支持输入种子重现相同游戏过程

### ✅ UI/UX优化
- [x] **医疗主题设计**: 蓝白主色调，温暖色彩点缀
- [x] **响应式设计**: 移动端优先，完美适配各种设备
- [x] **平滑动画**: 资源条动画、阶段过渡效果
- [x] **交互反馈**: 滑动选择、点击选择双重支持
